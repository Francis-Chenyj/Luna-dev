# Luna 1.6.1

2026-10-15 · FrancisChen · 本地修订 / Local revision

## 中文

- 设置页五个标签统一为圆角按钮，选中、悬停与键盘焦点保持一致。
- 使用说明及文档窗口的标题、关闭键固定在正文上方；正文单独滚动，到底部也可直接关闭，不覆盖文字。仍支持 Esc 关闭。
- 左上角 Luna 不再被外围焦点框包围；使用 Tab 键时以名称下划线标明焦点，保留键盘返回首页的能力。

本版调整界面表现，沿用 1.6.0 的本地查询、分路选择、数据更新和空间管理机制。程序包、源码包及双语说明同步更新，未上传或发布到 GitHub。验证结果见 [QA](QA-1.6.1.md)。

## English

- All five Settings tabs use rounded buttons, including selected, hovered and keyboard-focused states.
- Help and document dialogs keep their title and close control above a separately scrolling body. The close control remains available at the bottom without covering text. Esc remains supported.
- The Luna home link no longer has an enclosing focus outline. Keyboard focus underlines the name, retaining keyboard navigation to the home page.

This is a presentation fix retaining the local queries, lane selection, data updates and storage management from 1.6.0. Runtime/source packages and bilingual documentation are updated locally; no GitHub publication has been performed. See [verification](QA-1.6.1.md).
