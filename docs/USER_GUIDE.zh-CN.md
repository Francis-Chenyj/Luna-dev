## 安装与启动

运行需要 Windows 10 / 11、.NET Framework 4.7.2 或更高版本，以及微软 WebView2 Runtime。Luna 默认使用自有桌面窗口；缺少运行环境时从[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)安装，或用 `Luna.exe --browser` 启动不含托盘的兼容模式。普通使用无需开发工具、登录、API Key 或管理员权限。

GitHub 已有 [v1.5.0-dev.1 公开预发布](https://github.com/Francis-Chenyj/Luna-dev/releases/tag/v1.5.0-dev.1)。本指南介绍本地 1.6.6 修订；本地有新版不代表线上已经更新。如果你已拿到本地运行包：

1. 将 `Luna-v1.6.6-Windows.zip` **完整解压**到可写目录，例如 `D:\Apps\Luna`。不要直接在压缩包内运行，也不要只复制 EXE。
2. 保持 `Luna.exe`、`Luna.exe.config`、两个 Microsoft.Web.WebView2 DLL、`runtimes`、`web` 和 `data` 在同一目录。
3. 双击 `Luna.exe` 或 `启动Luna.cmd`，等待右上角显示本地运行状态。
4. 搜索英雄并选择分路；默认条件已随包提供，可以直接查询。

| 入口 | 用途 |
| --- | --- |
| `Luna.exe` / `启动Luna.cmd` | 查询本地数据，并允许后台与手动联网更新 |
| `离线启动Luna.cmd` | 查询已保存数据，禁止外网更新 |
| `创建Luna桌面快捷方式.cmd` | 为当前目录创建或更新桌面快捷方式 |
| 程序右上角 **退出** | 立即停止本地服务和后台更新 |

源码 ZIP 不含 EXE，需要按[开发指南](DEVELOPER_GUIDE.zh-CN.md)构建。若包旁有 `SHA256SUMS.txt`，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对 ZIP 与其中同名条目的哈希；校验值用于确认文件内容一致性。

Luna 只监听本机。普通入口默认使用端口 17653，离线脚本使用 17683；占用时尝试后续端口。程序不设置开机启动、系统代理或防火墙规则。标题栏关闭时可选最小化到托盘或退出。托盘保持后台更新；页面或托盘的“退出”立即结束。仅浏览器/无窗口模式保留 10–11 分钟闲置退出。

## 设置外观与排错

点击右上角 **设置 / Settings**。选择保存在程序目录的 `cache/settings.json`，同一程序目录的普通启动、离线启动和不同本机端口共享设置；升级时保留此文件夹。不同程序副本分别保存偏好。

| 分区 | 功能 |
| --- | --- |
| 常规 | 语言：跟随系统、简体中文、English。外观：跟随系统、深色、浅色。立即生效，保留当前英雄、分路、筛选条件及进行中的任务。 |
| 数据 | 启动时自动更新数据。开关 **下次服务启动生效**，不会立即发起或中止下载。进入数据管理可手动更新、补齐条件或停止任务。 |
| 排错 | 打开日志、数据目录；复制诊断信息并显示预览。浏览器不允许复制时，选中预览内容后按 Ctrl+C。 |
| 关于 | 查看 Luna 图标、版本、FrancisChen、项目主页、离线更新记录、原创代码 MIT 许可证及第三方声明。 |

跟随系统时，语言读取启动时的 Windows 显示语言：中文使用简体中文，其余使用 English；外观随系统深浅色变化。手动选择优先于系统。仅关闭窗口未必结束服务；调整启动更新开关后，请点 **退出** 再启动。

1.6.0 的自有窗口标题栏在系统支持时随主题变色，手动切换即时应用，系统变化约一秒内同步。高对比度保留系统标题栏颜色；旧版 Windows 与浏览器兼容模式可能保留系统外观。升级后请重启 Luna，实测结果与限制见 [QA](QA-1.6.0.md)。

离线模式始终禁止联网更新；`--no-auto-update` 启动参数始终禁止本次自动更新。保存的开关不能绕过这些限制。这里更新的是英雄与对局数据，不会自动下载或安装 Luna 程序。

数据入口打开 `cache/`，日志入口打开 `cache/logs/`。旧版 `cache/error.log` 原样保留；启动错误仍写入程序旁的 `启动错误.txt`。复制诊断只含 Luna 版本、运行模式、本次启动自动更新状态和本次进程的错误类别次数，不含原始错误、路径、账号、密钥或搜索记录，也不会自动发送。原始日志本身可能包含本机技术细节。

设置文件无法读取时，暂用系统语言与主题，并关闭启动自动更新；重新保存会保留损坏文件副本。来自不兼容未来版本的设置文件不会被覆盖。

## 搜索英雄与选择分路

可输入中英文姓名、称号、拼音、缩写或常见外号，例如 `李青 / 盲僧 / Lee Sin / the Blind Monk / 瞎子`、`厄加特 / Urgot / 螃蟹 / 蟹`。英文大小写、空格和常见标点不影响匹配；有歧义的外号会保留多个候选。

使用方向键选择候选，按 Enter 确认；**Ctrl+K** 回到搜索框。点击结果卡片可继续查询那个英雄。

| 操作 | 分路处理 |
| --- | --- |
| 首页搜索、选择首页候选，或点击任意页面的“最近 / 常用”英雄 | 从该英雄的常用分路开始 |
| 在英雄详情页继续搜索，或点击严父 / 大儿卡片 | 沿用当前分路 |
| 手动点击分路 | 使用你选的分路，后续详情页查询沿用它 |
| 浏览器前进 / 后退 | 恢复历史页面保存的分路 |

常用分路由本地目录中场次最多的可用分路确定；界面标注“默认分路”“沿用分路”“已选分路”或“恢复分路”。点击 Luna 回首页会结束这一轮分路上下文。

例如，在剑魔上路详情页搜索阿狸，会沿用上路；回到首页后搜索阿狸，则使用阿狸的常用分路。沿用的分路没有数据时，请手动选择提示中的有效分路。有效分路下的空结果不会自动换路，后台目录更新也不会改变正在查看的分路。

最近查询保存在浏览器本地存储中。更换浏览器或运行端口后，最近记录可能不同。

## 筛选与结果解读

左侧 **严父** 是克制当前英雄的对手，右侧 **大儿** 是被当前英雄克制的对手。两侧独立保留上游返回的分类、顺序、关系值和蓝色“共轭”标记，不由其中一侧反推另一侧。

| 控件 | 含义 |
| --- | --- |
| 分路 | 上路、打野、中路、下路、辅助；没有数据的分路不可选 |
| 严父阈值 | 克制强度筛选，1–5 档，同时影响两侧结果；越高越严格 |
| 场次严谨度 | 按上游样本量规则筛选，1–5 档 |
| 查看范围 | 在已保存结果中筛选分段分类，不增加下载量 |

默认阈值为 **1**、严谨度为 **5**。当前随包库覆盖 173 位英雄、428 个有效英雄分路、856 份双向记录；不意味着每个英雄都有五路数据。

阈值与严谨度共有 25 种组合，随包完整提供其中 1 种。其他组合需要自己的准确匹配数据；没有保存时，可恢复默认条件立即查询，或打开数据管理下载该组合。

“查看范围”有七类：全分段、高 / 中、仅高、高 / 低、仅中、中 / 低、仅低。按上游说明，高指大师+，中指钻石+，低指翡翠+。

- **“仅高分段”**只显示单独归类为高分段的关系，不包含高 / 中、高 / 低或全分段。
- **“全分段”**也是上游的一种分类；要同时看全部分类，请选 **“全部七类分段”**。
- 关系值**不是胜率**，不能加百分号；滑块档位也不是卡片关系值的直接下限。
- 蓝色“共轭”标记沿用上游定义，表示不同分段可能出现相反关系。
- “当前条件下没有符合关系”是合法空结果，与未保存数据、数据损坏或读取失败不同。

## 更新数据与离线使用

**查询始终读取本地；联网更新在后台独立进行。**启用启动数据更新时（初始默认开启），普通新服务启动约 1 秒后安排一次版本检查，默认条件及以前完整保存的条件会参与自动更新。版本未变且本地完整时不重复下载，也不会自动补齐全部 25 种组合。

| 入口 | 更新范围 |
| --- | --- |
| 首页 **更新离线库**，或 **数据管理** | 检查、下载或续传完整库；手动更新包含当前条件，可选择补齐全部 25 种组合 |
| 英雄页 **联网更新此英雄** | 只更新当前英雄、分路、阈值和严谨度的两侧结果，即使原站版本未变也重新获取 |
| 搜索框下方更新状态 | 查看进度、打开管理面板、停止更新或手动重试 |

后台优先处理当前及最近英雄，再续传完整库。英雄两侧结果验证成功后可先使用；不必等全库完成，也不会因此把整个库标为已更新。手动单英雄请求可在整库任务中优先处理。

- 更新成功后，当前页面自动读取新数据。
- 更新失败、主动停止或退出时，保留之前完整可用的结果和已验证的英雄更新。
- 断点续传要求原站版本仍匹配且临时记录尚未清理。尚未完整保存过的额外条件，下次需再次手动选择。
- 关闭数据管理面板不会停止更新；点击 **停止更新** 后，本次运行不会自行重启自动任务，手动更新仍可使用。
- 默认全库有 856 份记录，下载会限速；补齐全部组合可能耗时数小时。当前英雄仍先显示本地可用数据。

离线脚本禁止外网更新，已保存的默认与额外条件仍可查询。离线窗口中的网络按钮不可用，需要更新时改用普通入口。也可在设置 → 数据关闭启动自动更新，手动更新仍可用；高级启动参数见[开发指南](DEVELOPER_GUIDE.zh-CN.md#本地运行参数)。

数据更新**不会安装新版 Luna**；程序升级在 **设置 → 应用** 中单独管理。自动下载默认关闭，安装需确认；发布源需要提供通过签名校验的正式运行包。

1.6.6 开启自动下载时同时开启自动检查，并立即检查、下载符合要求的新版。关闭自动检查会同时关闭自动下载；只关闭下载则保留版本检查和已下载进度。手动下载仍可使用。离线或仅手动启动会提示设置已保存，但本次不会自动联网。升级成功重启后显示成功提示。完整规则见 [README 程序更新](../README.zh-CN.md#程序更新)。

## 查看数据来源与时间

两侧结果分别显示来源，不同来源或日期不会合并成一个“最近更新”。

| 来源标签 | 含义 |
| --- | --- |
| 程序自带数据 | 随包离线库；首次查询即可使用 |
| 联网更新的数据 | 以前下载并保存的完整库或英雄双向结果；这次查询仍读本地 |
| 备用旧数据 | 优先数据不可用时的上一份库、旧缓存或当前窗口同条件成功结果；旁边保留原来源 |

**数据生成**是原站生成这版关系数据的时间，不是查询时间或游戏补丁日期。**本机更新**是该份数据下载保存的时间；随包记录显示“此份随程序提供”，缺失时间显示“未记录”。

数据管理中的**上次成功检查原站**独立记录版本检查。只检查到版本没变，不会刷新本机更新时间。旧数据回退和查询重试会保留原日期。迁移整个文件夹也会保留这些时间，不将它们改成新电脑的安装日期。

## 升级备份与空间管理

1.6.0 完整运行包支持 **设置 → 应用 → 检查程序更新**。下载可续传，确认“重启并更新”后替换程序文件，保留设置及离线库；新程序本地健康检查失败时回退。尚无正式签名新版时继续使用现有版本。源码目录不会原位更新。

需要手动迁移或升级旧版时，先用程序内 **退出** 关闭旧服务，再按以下步骤操作：

1. 保留旧目录作为备份，将新运行包完整解压到另一个可写目录。
2. 启动新副本前，将旧目录的 `cache` **复制**到新目录，保留语言、主题、启动更新偏好，以及已下载条件、英雄更新和续传进度。原目录保持完整。
3. 从新目录启动 Luna。需要桌面入口时，重新运行 `创建Luna桌面快捷方式.cmd`。
4. 在 **设置 → 关于** 核对版本，确认原有偏好和已保存查询正常后，再自行决定如何保留旧备份。当前包不会自动迁移或删除旧目录。

原生窗口的最近查询位于 `cache/webview2` 的本地存储中；浏览器兼容模式则使用所选浏览器的配置。记录与来源地址相关，更换浏览器或端口后可能不同。同一版本号可能对应多份本地审阅包，应结合随包的 `SHA256SUMS.txt` 和逐文件清单识别目标构建，不能仅凭 ZIP 文件名判断。

| 位置 | 内容 |
| --- | --- |
| `data/` | 随包目录、离线关系、搜索词和头像 |
| `cache/settings.json` | 语言、外观和启动数据更新偏好 |
| `cache/library/` | 已下载完整库、上一份备份和可续传下载 |
| `cache/focus/` | 已验证的英雄双向更新与优先级记录 |
| `cache/detail-*.json` | 旧版保留的单条缓存 |
| `cache/logs/error.log` / `启动错误.txt` | 更新或启动故障记录 |

删除 `cache` 会丢失设置、已下载更新、本地日志和续传进度；随包默认库仍在。不要把删除缓存当作更新失败时的第一步。

空间维护在启动后延迟进行，成功完成后跨启动保留 24 小时间隔，下载写入后也会整理。每种组合保留当前完整库与上一份可用备份，未完成下载在 7 天无进展后可被清理。英雄缓存通常最多 64 组、8 MiB；确认损坏的英雄缓存及损坏设置备份进入最多 20 份、10 MiB、7 天的隔离区。被占用、归属不明及可能是最后可恢复数据的文件保守保留；这不是整个目录的硬容量限制。

**设置 → 数据 → 空间管理**按类别显示磁盘文件大小与统计时间，包括界面缓存和程序更新备份。查询本身不会持续新增整库文件；保存的组合及数据版本越多，占用越大。数字不是进程内存用量，也不是 Windows 磁盘“占用空间”。

可选运行 **安装Luna.cmd** 安装到新的空目录并加入 Windows 应用列表。卸载可从 **设置 → 应用**、**卸载Luna.cmd** 或安装版的 Windows 应用列表进入。默认保留用户数据并移除程序更新暂存；只有明确勾选才删除该目录的整个 `cache`。额外文件、改过的程序文件、其他副本和共享运行环境保留。详见[README 中的维护说明](../README.zh-CN.md#可选安装与卸载)。

## 故障处理

| 现象 | 处理 |
| --- | --- |
| 程序无法启动 | 确认已完整解压、目录可写且 .NET Framework 版本满足要求；查看 `启动错误.txt`，尝试较短的目录 |
| 页面提示本地服务断开 | 重新双击启动入口，再点 **重新连接**，或使用新打开的窗口；已经显示的结果仍可阅读 |
| 选择某个条件后提示尚未保存 | 恢复默认 1 / 5，或联网下载当前条件；不要把缺失数据当成没有克制关系 |
| 当前分路不可用 | 选择页面列出的有效分路；不会自动替你换路 |
| 更新未完成 | 先继续使用已有数据；稍后在普通入口重试。离线入口不能联网更新 |
| 查询失败或超时 | 短暂故障最多自动重试两次，总等待上限 5 秒；之后可点 **重新查询**。损坏或不匹配数据会单独提示 |
| 显示旧日期或备用旧数据 | 查看两侧来源与数据管理状态；检查版本、重新查询并不等于已下载新数据 |
| 移动目录后快捷方式失效 | 在新目录重新运行创建桌面快捷方式脚本 |
| 普通浏览器的任务栏图标没有变成 Luna | 普通标签页使用浏览器图标；直接启动 Luna.exe 使用原生窗口与图标 |
| 刚关闭窗口，服务似乎仍在运行 | 托盘模式会继续运行；需要结束时使用页面或托盘的 **退出**。只有浏览器/无窗口模式采用闲置超时 |
| 升级后仍显示旧界面 | 确认从新解压的完整目录启动，再按 Ctrl+R 刷新；旧目录的快捷方式可能仍启动旧副本 |

## 1.6.0 窗口、关闭与托盘

本版默认使用自有桌面窗口，依赖微软 WebView2 Runtime。电脑通常已有；缺少时请从[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)安装。请保留完整解压后的两个 Microsoft.Web.WebView2 DLL 和 runtimes 目录。`Luna.exe --browser` 可进入无托盘的浏览器兼容模式。

点击标题栏 × 或按 Alt+F4，默认询问“最小化到托盘区 / 退出应用”，可勾选记住选择；在“设置 → 常规 → 关闭窗口时”可随时更改。托盘模式继续运行已有更新任务，双击绿色 L、右键“打开 Luna”或再次启动同一快捷方式可恢复原窗口和查询。页面和托盘菜单的“退出”始终结束程序及后台更新。Windows 关机/注销不弹关闭询问。浏览器/无窗口模式仍保留 10–11 分钟闲置超时。

旧版本的语言、主题、下载数据继续使用。旧 Edge 的最近查询属于其浏览器存储，不自动迁移；新窗口记录保存在 cache/webview2。启动时异步清理 WebView2 磁盘与站点缓存，不删除最近查询、设置或英雄数据。WebView2 配置目录及系统共享运行环境属于额外空间，先前的对局数据空间估算不包含它们，不承诺固定的目录总大小。

Windows 11 支持的标题栏颜色随深色、浅色及系统主题切换；Windows 10 等系统可能保留部分系统颜色。高对比度使用系统标题栏颜色。页面尚在加载或损坏时，原生询问框提供“是：托盘 / 否：退出 / 取消”，此应急询问不保存记住选择。
